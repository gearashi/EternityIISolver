# Search improvement decisions

The 67 proposals below were reviewed against the existing five-clue solver and compared on finite workloads. A decision can concern a dashboard setting, a research-only implementation, or a particular repair family. The original puzzle still has no verified 480 in these runs. [Settings, measurements and proof replay](SEARCH_SETTINGS.md)

## Regional decomposition and bounds

| ID | Proposal | Disposition | Evidence and scope |
|---:|---|---|---|
| 23 | Partial piece-allocation conflict cores | Kept proof-minimized allocation cuts in regional master | A completed failure proof records which pieces needed to stay outside the region. On 24 completed physical test pairs, local placements fell from 582 to 246 and native master branches from 26,542 to 3,630. Core-only hit the query cap on one original-puzzle control. |
| 24 | Regional color-conservation equations | Kept shared interior-edge color constraints in regional master | For each stable color, allocated sides equal twice the internal matches plus exposed sides. Omitted grid edges contribute bounded slack. Tested a deliberately nonrotational state table and partially constrained grids. Adding this option alone reduced local placements to 512 and native master branches to 9,788 across the same 24 cases. The joint mode also shares one feasible color per internal edge, which improves these aggregate counts on the additional tests below. |
| 25 | Regional Hall-capacity cuts | Kept reusable Hall capacity inequalities in regional master | On the same 24 pairs, local placements fell to 523 and native branches to 6,245. This covers a bounded family of Hall inequalities. A new case with multi-set Hall shortages could justify a wider family. |
| 26 | Positive interface relations | Rejected eager and delayed pattern implementations | Forward compilation on 24 pairs took 1,266 attempted placements versus 197 in the joint mode. Native master branches rose from 645 to 7,070. Waiting for two failures of the same pool and retaining the ordinary rejection cuts tied the joint mode at 388 placements on 48 paired cases and added 948 operations. Revisit if a real scope incurs repeated expensive failures of an identical exact pool. |
| 27 | Persistent regional oracle learning | Rejected as joint-master default, persistent SAT reuses some work | On 24 completed pairs, keeping an assumption-scoped Glucose solver reduced local SAT decisions from 260 to 216 and native propagations from 2,612 to 2,446 compared with rebuilding the same oracle. The default joint DFS used 199 local placements and 475 native master branches. The persistent SAT route used 396 native master branches plus its 216 local SAT decisions. Each kind of work is reported separately. |
| 28 | Conflict-driven repartitioning | Rejected tested repartitioning and ownership variants | On 28 pairs, native branches fell from 645 to 319, but local placements increased from 521 to 797 and explicit work from 50,995 to 68,370. Revisit if a partition change can preserve the previously learned cuts. |
| 29 | Hierarchical regional masters | Rejected tested repartitioning and ownership variants | The multilevel experiment took 909 placements and ownership choices versus 521 in the joint mode. The suite included nine-cell rows long enough to subdivide through multiple levels. |
| 30 | Deliberately create independent components | Rejected tested repartitioning and ownership variants | A one-level split took 837 choices versus 521. The two residuals are independent only after color interactions and physical ownership are resolved. Reopen on large residuals separated by few choices. |
| 31 | AND/OR search with context caching | Kept positive exact regional witness cache | Caching an exact pool and all incident colors saved 144 local placements on the original 24-pair suite and tied native branches. On the nested route, context caching saved 72 placements against uncached nesting but still took 837 total choices versus 521 in the joint incumbent. No cross-run reuse. |
| 32 | Regional meet-in-the-middle search | Rejected eager and delayed pattern implementations | Matching complementary physical-piece masks and crossing colors gave a complete local relation, but consumed 1,397 attempted half placements versus 1,266 in forward compilation and 197 for the joint master. Revisit if many compatible regions can reuse a precomputed half. |
| 33 | Exact elimination of low-width residual regions | Kept as exact/relaxed bounded residual API | Exact buckets retain global uniqueness through pairwise collision factors. A full witness is independently checked when all buckets fit. The actual SAT-target comparison below charges the enumeration work. |
| 34 | Generate regional arrangements as needed | Rejected eager and delayed pattern implementations | The solver tried eager generation, a two-frontier join, and failure-triggered generation. See items 26 and 32. Incomplete generation discarded the entire candidate table before fallback. A pricing approach that can certify useful missing patterns without generating a whole table would be a different experiment. |
| 35 | Track piece-group capacities before individual identities | Kept for narrowed DD API only | On a broad 40-case suite, 9,841 refined transitions rose to 11,429. On 32 fresh restricted cases, 3,405 fell to 3,324 with 8 wins and 4 losses. Explicit work rose from 150,347 to 164,060. |
| 36 | Choose identity refinements from recurring conflicts | Rejected tested history-guided refinement | All 40 transition counts tied the incumbent frequency rule and counting history added work. Revisit if many repeats persist across diagrams and compete for a limited refinement batch. |
| 37 | Refine only problematic diagram nodes | Kept for narrowed DD API only | Broad-suite transitions rose to 15,552. On the 32 held-out restricted cases, transitions fell from 3,405 to 3,327, with 2 wins and no losses. Work rose to 153,282. The full-puzzle diagram keeps its existing refinement choice. |
| 38 | Forget identities after their last possible future use | Kept as optional diagram policy | On 40 completed pairs, requiring use before expiration reduced exact-identity transitions from 25,806 to 25,708 and refined transitions from 11,261 to 11,163. Explicit work rose by 3.9% and 3.2%. Projection alone saved fewer transitions. All three original-board controls tied on transitions and added setup work. |
| 39 | Use diagrams to prune ordinary DFS or SAT | Rejected automatic DD front end, kept bounded marginal API | On 12 narrowed physical inputs, ordinary DFS needed zero branches while building the full-identity support diagram needed 279 placements. All 168 target-incompatible cell states were removed soundly. Revisit if a branch-heavy low-width case or many repeated queries amortize the compilation. |
| 40 | Weighted diagrams and reusable pattern bounds | Rejected automatic DD front end, kept bounded marginal API | Complete tables give a mismatch bound for every supported placement. Independent exhaustive tests check the minima, the physical pieces, and several thresholds per table. The 12 narrowed full-identity diagrams recovered all 12 exact global minima. |
| 41 | Mini-bucket bounds | Kept as exact/relaxed bounded residual API | Every edge mismatch is charged once. A split relaxes the equality of the eliminated variable between its groups. Width 3 attained the true optimum on 11 of 12 narrowed physical cases versus 6 of 12 with optimized overlapping regions, with 11,359 versus 23,173 algorithm-specific explicit operations. |
| 42 | Stronger global relaxation bounds and reduced-cost fixing | Kept optional price-bounds repair profile | Among those 12 cases, the checked LP proposal recovered the true minimum on all 12. Solver proposals are rounded to bounded integer edge potentials. A verified global bound and per-state bounds are recomputed using integer arithmetic. |
